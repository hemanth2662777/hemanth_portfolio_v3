## 🌟 Overview

This portfolio showcases the technical skills, projects, certifications, and experience of **Chelimala Hemanth** (Computer Science & Engineering graduate, full-stack developer, and ML engineer).

### Key Features

- **🎮 Immersive Sci-Fi / Anime System UI**: Dynamic neon borders, cybernetic HUD layout, subtle Web Audio sound effects, and ambient particle effects.
- **⚡ Interactive AI & ML Simulators**:
  - **CNN Rice Grain Classifier Simulator**: Interactive multi-class grain inference playground with real-time confidence scores and pipeline diagrams.
  - **Credit Risk & Loan Default Calculator**: Real-time DTI (Debt-to-Income) ratio analysis, logistic regression scoring model, and dynamic risk categorizations.
- **📄 Resume Download & Inspection**: Direct PDF resume download and embedded preview drawer.
- **📱 Fully Responsive**: Optimized for ultra-wide screens, laptops, tablets, and mobile smartphones.
- **📫 Direct Communication Terminal**: Form validation, toast feedback, and quick clipboard copy utilities.

## 🚀 Getting Started Locally

Follow these steps to run the project on your local machine:

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm or yarn / pnpm

### Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/heman2662777/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Start the local development server**:

   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

## 🏗️ Available Scripts

- `npm run dev` - Starts the development server at `http://localhost:3000`
- `npm run build` - Builds the optimized production bundle into the `dist/` directory
- `npm run preview` - Locally preview the production build
- `npm run lint` - Runs TypeScript type check validation (`tsc --noEmit`)

## 🌐 Free 1-Click Deployment

You can deploy this project in minutes on any modern web host:

### Deploy to Vercel

1. Push this repository to your GitHub account.
2. Go to [Vercel](https://vercel.com/) and click **"Add New Project"**.
3. Select your GitHub repository and click **Deploy**.

### Deploy to Netlify

1. Go to [Netlify](https://www.netlify.com/) and choose **"Import from Git"**.
2. Select your repository and click **Deploy Site**.
